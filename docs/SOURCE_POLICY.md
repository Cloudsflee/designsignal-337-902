# Source and Access Policy

DesignSignal collects only public metadata, RSS/Atom, bounded public pages, allowlisted images, and verified open-access PDFs. It never attempts login, CAPTCHA solving, paywall bypass, session reuse, access-control evasion, or scraping of private WeChat/Zhihu content. Optional RSSHub URLs must expose public feeds and remain subject to the same host, DNS, timeout, retry, MIME, and byte controls.

Default coverage includes one combined Tsinghua, Zhejiang and Tongji OpenAlex query, international HCI labs, general OpenAlex and arXiv; Core77, Dezeen, Designboom, Yanko Design, Awwwards and Product Hunt; and SSPAI, OpenAI, DeepMind, Microsoft Research and Hugging Face. Inaccessible institutional listings are optional. A source failure is recorded as degraded, and a zero-item source is recorded as empty. Neither triggers fabricated filler. OpenAlex 429 and request-budget exhaustion remain explicit in source health while arXiv collection continues independently.

Stanford institutional news uses the public `hai.stanford.edu/news` listing and accepts only `/news/` article paths from its server-rendered Next Flight data. CMU HCII parsing is restricted to the `newsfront-cards` container and `/news/` paths. When a CMU card has no date, collection may read at most eight details from that same hostname and accepts only an explicit publication `<time datetime>` or visible full date. Month/day-only cards infer the current year, rolling into the prior year only when the result would be more than 24 hours in the future. Navigation, topic, people, and external media links cannot consume the detail budget.

Candidate origin language belongs to each item, not its institution. OpenAlex uses `work.language` when it is zh/en, infers conservatively from title and abstract only when that field is absent, and otherwise records unknown. Feed and listing items infer from their own title and summary; configured locale is used only as an explicit, recorded fallback.

## Priority-institution paper policy

The production configuration recognizes only the structured OpenAlex institution IDs `I99065089` (Tsinghua), `I76130692` (Zhejiang), and `I116953780` (Tongji). The OpenAlex adapter normalizes institution IDs across every authorship and records the author/institution indexes, normalized identity, and exact configured matches as candidate provenance. Locale, source labels, institution display text, query membership, and translated titles never establish priority. Missing, unmatched, or malformed affiliation provenance leaves a work in the ordinary ranking pool.

Priority is deliberately bounded. A non-duplicate paper must pass all ordinary provenance, URL, date, origin-language, freshness, and category checks; be strictly less than seven days old; and score no more than five points below the best eligible paper. Qualifying priority papers are evaluated in deterministic score order. The highest-ranked candidate that is already selected or has a deterministic paper replacement preserving the exact `2/1/1/2` category quota, both zh/en origin-language coverage, unique selected IDs, and at least four distinct sources occupies one of the two paper slots. `no-safe-replacement` is reported only after every qualifying candidate has been evaluated. No threshold is relaxed to force a result.

`audit.selectionPolicy.priorityInstitutionPaper` records the configured IDs and thresholds, match/validation/freshness/eligibility counts, ineligibility counts, decision and exact reason, selected item/source/institution, and any replaced item/source. Decisions distinguish rank satisfaction, quota-preserving replacement, no structured match, all candidates deduplicated or otherwise invalid, strict-freshness failure, relative-quality failure, and absence of a safe replacement. Replaced ranked items use the explicit `priority-institution-replacement` rejection reason; unmatched or malformed affiliations remain ordinary candidates with ordinary ranking outcomes.

New reports use `schemaVersion: 4` and must contain the complete priority-institution audit plus deterministic briefing classification, official 337/902 coverage, and ordered review references. Stored `schemaVersion: 2` and `schemaVersion: 3` reports remain readable and recoverable under their original contracts. Read and recovery paths derive a compatibility view in memory without upgrading, reserializing, or changing a stored report or its manifest hash.

The append-only manifest records each selected item ID and its bounded credential-free source URL. Canonical URL dedupe therefore survives upstream item-ID changes. For a legacy manifest entry without URLs, history lookup may derive them in memory only when the referenced immutable report has the expected path, matches the recorded SHA-256, and passes its original report schema. It never rewrites the legacy entry. The dashboard likewise checks the latest entry's calendar date, canonical report path, SHA-256, and report date before returning content.

Only selected items in a writable live daily run enter the asset stage; fixture and dry-run paths never write. Every cached object records URL, retrieval time, MIME, byte count, SHA-256, author, institution, access status, license status, and a local cache reference. PDFs require an explicit OA signal; unknown-license PDFs remain links. Selected public product/UI images and bounded public article text are cached when validation succeeds. Content signatures reject HTML masquerading as images or PDFs. Failures remain explicit audit entries and never trigger filler. Collection rejects non-HTTP(S) URLs, credential-bearing URLs, hosts outside the allowlist, private/link-local/reserved DNS results, unsafe redirects, oversized bodies, and excess feed/API rows.

Every production HTTP(S) connection uses the same public IP set that passed DNS validation, preserving the original Host header and TLS SNI while preventing a second untrusted lookup. IPv4-mapped IPv6, unique-local, link-local, multicast, documentation, and reserved results receive the same blocking policy as private IPv4. Redirects are validated again. GET/HEAD requests retry only transient transport failures, 408, 425, 429, and 5xx with bounded delay; definite 4xx responses stop immediately. Side-effecting POST requests are neither replayed nor allowed to follow redirects. Institutional domains that resolve to private space, including the currently observed Zhejiang `10.203.*` results, remain blocked rather than allowlisted around the SSRF policy; structured OpenAlex institution evidence supplies the fallback.

Credibility is evaluated from provenance and evidence, not brand alone. Reports preserve primary links, distinguish claims from methods, state limitations, and retain all rejected/degraded audit records. The 60-day dedupe uses stable item IDs plus canonical URLs retained in the manifest or verified legacy report.
